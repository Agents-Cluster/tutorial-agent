## 🎯 如何使用本结构

### 1️⃣ 快速查找
→ 使用 `INDEX.md`（按用途、主题、缺陷、优先级查找）

### 2️⃣ 系统学习
→ 按照本文件的"推荐阅读路径"逐个阅读

### 3️⃣ 定期回顾
→ 根据当前阶段选择相关文档
- 需求阶段 → `02-系统设计/`
- 开发阶段 → `04-实施指南/`
- 测试阶段 → `04-实施指南/13-代码检查清单.md`
- 上线阶段 → `03-专项设计/09-部署运维.md`

### 4️⃣ 引用
→ 复制相应文件的链接放在PR、会议记录、设计文档中

## 💡 使用建议

### ✅ 做这些事
- 📖 在项目启动时，让所有团队成员读 README.md
- 🔗 在PR中引用相关设计文档
- 📝 在会议记录中添加文档链接
- 🎯 用 INDEX.md 快速定位需要的文档
- ⚠️ 在发现问题时，查看 05-问题分析/ 了解是否是已知问题

### ❌ 避免这些事
- 🚫 不要把文档直接复制到代码注释中（保持单一参考源）
- 🚫 不要修改文档前三部分（架构级别），只在实施指南中打补丁
- 🚫 不要删除旧的评估报告（保留历史追溯）
- 🚫 不要跳过 README.md 直接看细节文档
