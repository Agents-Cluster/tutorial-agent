# 难度与风险评估 Agent Prompt

## 职责

输出**难度等级**与**安全风险清单**。风险只描述原文提到或动作本身必然伴随的危险，不做"教程是否正确"的判断（那是平台边界之外的事，见 5.5.5）。

## 难度判定标准（写进 Prompt，避免模型自由发挥）

| 等级 | 判据（满足任一） |
| --- | --- |
| `easy` | 步骤 ≤ 5 且无热源、无电动工具、无锐器 |
| `medium` | 步骤 6–12，或使用锐器/热熔胶，或有"需要等待固化"的环节 |
| `hard` | 步骤 > 12，或使用电钻/电锯/明火/化学胶，或需要精确尺寸与多次试错 |

> "步骤数"按**原文正文中能分辨的独立操作步骤**计数：本 Agent 只读 `cleaned_text`，**不读结构化步骤列表**（四路并行约定，见 8.1.1 与 README）。原文步骤数不明确时按动作复杂度保守就高，漏判由质检 `risk_suspect` 兜底（见文件末尾）。

## 风险类型枚举

`cut`（割伤）/ `burn`（烫伤、明火）/ `electric`（触电）/ `chemical`（化学品、胶水挥发）/ `dust`（粉尘）/ `tool`（工具伤害）/ `other`

## Prompt

```
你是手工教程的难度与风险评估助手。请判断这个教程的难度，并列出操作中的安全风险。

难度判定（步骤数按原文正文中能分辨的独立操作步骤数判断，数不清按复杂度保守就高）：
- easy：步骤 ≤ 5，无热源、无电动工具、无锐器
- medium：步骤 6~12，或使用锐器/热熔胶，或需要等待固化
- hard：步骤 > 12，或使用电钻/电锯/明火/化学胶，或需要精确尺寸

风险要求：
1. 只列原文中提到、或该动作必然伴随的风险，不要编造；
2. 每条风险给出等级（high/medium/low）、类型、描述、缓解措施；
3. 缓解措施要具体可执行（"戴防割手套"优于"注意安全"）；
4. 没有风险时输出空数组，不要硬凑；
5. 严格输出 JSON，不要输出任何其他内容。

输出格式：
{
  "difficulty": { "level": "easy", "reason": "5 步以内，仅使用美工刀，无热源" },
  "risks": [
    { "level": "medium", "type": "cut", "desc": "美工刀裁切时可能割伤手指", "mitigation": "垫切割垫、戴防割手套、刀片朝外" }
  ]
}

教程文本：
"""
{{cleaned_text}}
"""
```

## 输出示例

```json
{
  "difficulty": { "level": "medium", "reason": "共 8 步，使用热熔胶枪，需等待固化" },
  "risks": [
    { "level": "high", "type": "burn", "desc": "热熔胶枪喷嘴温度可达 190℃，接触皮肤会烫伤", "mitigation": "使用支架放置胶枪，不要徒手清理余胶" },
    { "level": "low", "type": "chemical", "desc": "白乳胶有轻微气味", "mitigation": "在通风处操作" }
  ]
}
```

## 解析与校验

| 检查 | 处理 |
| --- | --- |
| `difficulty.level` 不在枚举内 | 回退为 `medium` 并记 `enum_fallback_total` |
| `difficulty.reason` 为空 | 保留等级，理由置为"模型未给出"，并按 5.4.2 惩罚项表扣 **0.05** |
| `risks[].type` 不在枚举内 | 归入 `other` |
| `risks` 为空但步骤含"高温/明火/电钻/刀" | 由**代码**在汇总阶段用 `steps_json` 复查（本 Agent 不读步骤，见文件开头），触发质检 `grounding_issues`（漏风险） |
| 单条风险 > 15 条 | 截断并记异常 |

> **风险不是置信度的一部分**：漏风险不会直接扣分，但会在 `quality_flags` 里标 `risk_suspect`，由复核员确认——因为"该不该报警"本身有主观性，不适合量化成扣分。
