# 步骤拆解 Agent Prompt

## 职责

把连续叙述的教程正文拆成**有序、可执行、单动作**的步骤序列，并标注每步用到的材料/工具。

## 五条约束

1. **不合并**：原文分成两步的，不要合成一步（"裁纸并折好"视为两步）；
2. **不过细**：一句话描述一个完整动作的，不要拆成"拿起刀""放下刀"；
3. **保持原序**：严格按原文出现顺序编号，不得"优化"顺序——顺序错了是质检的活，不是你的；
4. **动作句**：`action` 用动词开头的短句，不写"第一步"、不写序号；
5. **不补充**：原文没写的动作不要加（"等待干燥"若原文没写，不要脑补）。

## Prompt

```
你是手工教程的步骤拆解助手。请把教程原文拆解成有序的操作步骤。

要求：
1. 每个步骤是一个独立的、可执行的动作，用动词开头的短句描述（不超过 40 字）；
2. 严格按原文顺序排列，用 seq 从 1 开始连续编号；
3. 标注该步骤用到的材料或工具名称（用原文写法，不要自造名称——本 Agent 看不到清单，后端会用同义词表归一化后与材料/工具清单比对）；
4. 原文中该步骤附带的警告（"小心烫伤""注意通风"）放进 warnings 数组；
5. 原文给出时长的，填入 duration_est（如 "5min"），没有则为空字符串；
6. 不要合并步骤，不要拆分过细，不要添加原文没有的动作；
7. 严格输出 JSON，不要输出任何其他内容。

输出格式：
{
  "steps": [
    {
      "seq": 1,
      "action": "沿虚线裁切纸张",
      "uses": ["牛皮纸", "美工刀"],
      "duration_est": "5min",
      "warnings": []
    }
  ]
}

教程文本：
"""
{{cleaned_text}}
"""
```

## 输出示例

```json
{
  "steps": [
    { "seq": 1, "action": "按 A4 尺寸裁切牛皮纸", "uses": ["牛皮纸", "美工刀"], "duration_est": "5min", "warnings": ["注意手指"] },
    { "seq": 2, "action": "沿中线对折并压平", "uses": ["牛皮纸"], "duration_est": "2min", "warnings": [] },
    { "seq": 3, "action": "用白乳胶粘合边缘，静置 10 分钟", "uses": ["白乳胶"], "duration_est": "10min", "warnings": [] }
  ]
}
```

## 解析与校验

| 检查 | 处理 |
| --- | --- |
| `seq` 不连续 / 重复 | 按数组顺序重排为 1..n，记 `seq_fixed_total` |
| `action` 为空或超 40 字 | 丢弃该条，并按 5.4.2 惩罚项表扣分（0.05 × 丢弃条数，上限 0.15）；阈值与 Prompt 约束的 40 字一致 |
| `uses` 中的名称不在材料/工具清单里 | 保留原值，但计入质检 `grounding_issues`（可能是幻觉实体） |
| `steps` 长度 > 40 | 大概率把整段原文当步骤，截断并记 `agent_anomaly_total{type="too_many_steps"}` |
| `steps` 长度 < 2 且原文 > 500 字 | 拆解不足，触发质检 `missing_fields` |

> 顺序合理性**不由本 Agent 判断**。是否颠倒由质检 Agent 输出冲突对、代码扣分（见 5.4.2），避免"自己拆自己判"。
