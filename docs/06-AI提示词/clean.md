# 清洗 Agent Prompt

## 职责

从 UGC 教程原文中剥离**与操作无关**的内容（广告、闲聊、平台口号、重复段落），输出可直接供下游抽取的正文。

## 三条铁律

1. **只删不改**：不得改写、合并、润色任何句子，输出必须是原文的子集（按段落顺序拼接）；
2. **疑似必留**：句子里出现材料名、工具名、数量、单位、时间、温度、尺寸、警告词的，**一律保留**，宁可留噪声也不误删；
3. **不翻译、不总结、不补充**。

## Prompt

```
你是手工教程的文本清洗助手。请从下面的教程原文中删除与"如何完成这个手工"无关的内容，其余原样保留。

需要删除的内容（reason 取值）：
- ad        广告、带货链接、店铺/公众号引流、"点击关注"
- chat      作者闲聊、感叹、与操作无关的个人经历
- meta      平台套话（"本文由xx编辑""转载请注明"）、版权声明
- duplicate 完全重复的段落（保留第一次出现）
- broken    明显的乱码、OCR 错误片段

必须保留的内容：
- 任何提到材料、工具、数量、单位、尺寸、时间、温度的句子
- 任何包含警告、注意事项、"小心""注意""危险"的句子
- 步骤描述、编号列表、标题

输出要求：
1. cleaned_text：删除后的正文，保持原有段落顺序与换行；
2. removed_spans：被删除的片段数组，每项只需 {reason, text}，text 必须是原文中**连续且完整的一句/一段**，不要改写、不要拼接；
3. kept_ratio：cleaned_text 字数 ÷ 原文字数，保留 2 位小数；
4. 严格输出 JSON，不要输出任何解释。

输出格式：
{
  "cleaned_text": "...",
  "removed_spans": [{"reason": "ad", "text": "点击链接购买同款材料"}],
  "kept_ratio": 0.78
}

教程原文：
"""
{{raw_text}}
"""
```

## 输出示例

```json
{
  "cleaned_text": "准备两张 A4 牛皮纸和一瓶白乳胶。\n用美工刀沿虚线裁切纸张，注意手指。\n折叠成型后压平 10 分钟。",
  "removed_spans": [
    { "reason": "ad", "text": "点击链接购买同款材料，店铺有优惠" },
    { "reason": "chat", "text": "我上次做这个失败了三次哈哈" }
  ],
  "kept_ratio": 0.62
}
```

## 解析与校验（代码侧，不依赖模型自觉）

| 检查 | 处理 |
| --- | --- |
| `removed_spans[].text` 在 `raw_text` 中唯一命中 | 补 `start/end` 后落库 |
| 命中多处 / 未命中 | 丢弃该 span，`span_drop_total{reason="not_found"}` +1 |
| `raw_text[start:end] != text` | 视为无效 span，不落库 |
| `kept_ratio < 0.5` **或** span 命中率 < 0.5 | 判定过度清洗 / 输出偏离：该条标 `clean_degraded`，按 5.4.2 惩罚项扣 **0.10**，进人工复核（两个条件是 OR，与 5.1.5 同口径） |
| `kept_ratio > 0.98` | 判定几乎未清洗：记 `clean_noop_total`，不扣分（原文可能本来就干净） |

> 偏移由后端计算，模型**不输出** `start/end`——见 5.1.5。
